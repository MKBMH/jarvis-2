JARVIS 17.0 — SUPREME INTELLIGENCE · THE SUPREME PROTOCOL · BUILD 17.1

INSTALLATION
1. Back up your existing repository, including the current JARVIS 16.0 files.
2. Replace index.html and sw.js at the same existing deployment path. Keep your icons, backend configuration, manifest and other files. The unchanged manifest is included for convenience.
3. Once deployed, open the existing website with ?v=17-supreme1 (or &v=17-supreme1 if a query exists), close and reopen the Home Screen app, and check BUILD 17.1. Do not clear website data: this may erase saved notes, reminders or vault records.
4. Open Supreme Intelligence or enter /supreme. Each of the twelve tabs is also accessible using /supreme sentinel, /supreme truth, /supreme global, /supreme sky, /supreme footprint, /supreme shield, /supreme road, /supreme voice, /supreme memory, /supreme finance, /supreme disaster or /supreme decision.

SCOPE
Based on the supplied JARVIS 16.0 BUILD 16.1 HTML and service worker. All 89 previous module identifiers retained in order; one additional module with 12 workflows, 90 total. Existing implementations are reused, not copied into new standalone modules. Four substantial additions: local claim-review checklist, manual journey-cost comparison, search across existing local notes/reminders, and a transparent weighted decision calculator. Emergency readiness checklist is session-only. No new external paid API, subscription, backend or storage keys. Existing notes and reminders remain in their existing storage. Keep sensitive information in the existing encrypted vault, not unencrypted notes.

LIMITATIONS
External aviation and alert sources are reused; coverage, uptime and free features depend on providers. No private feeds or background monitoring added. The Truth Detector flags text patterns and records user verification steps, not independently verified facts. Road Master compares user-supplied estimates, not live routing or current ERP calculations. AI Decision Engine is a local weighted scoring worksheet; it does not invoke an AI model. Optional external ChatGPT/AI usage is subject to existing plan or API fees. Voice and CarPlay rely on existing native shortcuts and permissions. This build does not make the website private; authentication remains separate.
