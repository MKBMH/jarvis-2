INSTALL
This update is based on the recovered JARVIS 15.0 Public Security Screening package (87 modules). The later 30 KB uploaded HTML is labelled JARVIS 2.0 and was not used to avoid losing the 15.0 modules. If the deployed app has additional changes, back it up and merge the parking update instead of overwriting it.
Back up existing files and local records. Replace index.html and sw.js in your existing GitHub Pages repository; keep all other files, icons, manifest and private Worker unchanged. The unchanged manifest is included for completeness. Once deployed, open your existing URL with ?v=15-parking1 appended. Do not delete the Home Screen app or clear site data. The existing service worker uses a new cache identifier.
Type /smartparking or tap Open Smart Parking Centre. The six modes use public HDB data, official LTA links, promotion searches, Waze deep links and a local price comparison. HDB data describes eligibility and hours, not live lot availability. GPS is optional and used locally for approximate straight-line ranking within 3 km. Mall, motorcycle and free overnight offers require verification at source; no automatic free parking guarantee. Night parking eligibility does not imply free parking. Manual price comparison requires total costs for the same period. No new paid API, account, key or backend changes. Ordinary parking fees may still apply. Avoid entering private information in public search links.
