INSTALL
Back up unfinished cases, recordings and private archives first. Upload index.html, sw.js and manifest.webmanifest to the root of your existing GitHub Pages repository, replacing the same filenames. Keep other files, icons and your existing private Worker unchanged. After deployment open https://mkbmh.github.io/jarvis-2/?v=15-screening1. If an older build appears, test in a new Safari Private tab before changing any saved site data. Do not delete the original Home Screen app or clear site data.

Open /publicsecurityscreening via the clickable command directory. The new centre reuses the existing caller, scam worksheet, Cyber Intelligence, cyber threat catalog and Sentinel public safety workflows. The new local government-domain inspection parses HTTP(S) links without visiting them. It cannot verify ownership, redirects, reputation, or safety. The checklist is session-only; export produces an unencrypted text file. Avoid sensitive details. Provider sites receive normal browsing requests when opened; no pasted screening data is automatically sent to them. Official ScamShield app checks and MAS/SPF resources are on-demand external services, not an embedded police database or an automatic live reputation API. No new paid integrations, API keys, or backend changes. Carrier charges may apply for telephone calls.
