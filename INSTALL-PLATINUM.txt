JARVIS 13.0 PLATINUM — installation

1. Keep a copy of your existing GitHub files. Replace index.html, sw.js and manifest.webmanifest in the same GitHub Pages repository. Leave existing icons, backend, credentials, and other files unchanged. Do not clear website data: it may remove local JARVIS settings.
2. Open the published JARVIS website in Safari, refresh, then close and reopen the home screen app. Look for JARVIS 13.0 and Platinum. Existing Home Screen labels may stay unchanged.
3. Install only the native apps you need. In iPhone Shortcuts tap +, add Open App, select the app, rename exactly, and save. Test each shortcut locally, then tap its JARVIS button.
4. Use /platinumsetup to view and copy shortcut names. Use /shortcutcheck to test and manually record success. No JARVIS AI token is required for these local actions.
